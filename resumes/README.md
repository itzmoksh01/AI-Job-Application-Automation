# Resumes

Put your resume PDFs here:

| File | Used for |
|---|---|
| `master_resume.pdf` | Fallback when no variant clearly fits |
| `prompt_engineering.pdf` | Prompt Engineer / prompt-focused roles |
| `ai_automation.pdf` | AI Automation / workflow roles |
| `ai_agent.pdf` | AI Agent / autonomous-workflow roles |
| `ai_video.pdf` | AI Video / generative media roles |
| `ai_content.pdf` | AI Content Generation / creative AI roles |

The five tailored variants are already included. Variants must re-emphasize
real experience only — never invent claims. The bot picks the best-matching
variant per listing automatically (see `src/resume_picker.py`).
